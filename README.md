# Instance Page v1

### *The original Stux.Cloud instance page, preserved.*

An archived, pinned snapshot of [StuxCloud/instancepage](https://github.com/StuxCloud/instancepage), frozen at its `0e2f1ba` commit — the last state of the page before its modern redesign. This repository exists so the original design stays available and independently versioned as `v1`, separate from the live template's ongoing development.

## Overview

This is a lightweight, self-contained HTML landing page used to announce Stux.Cloud instances or services while they're still in development. No build step, no dependencies beyond a CDN stylesheet.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/StuxCloud/instancepage-v1.git
   ```

2. Run it locally:
   ```bash
   ./dev-server.sh        # or dev-server.bat on Windows
   ```
   Then open the printed `http://127.0.0.1:8000` URL. You can also just open `index.html` directly in your browser, or deploy it to your hosting provider.

## Scope

This repository is an archive, not the actively developed template. Contributions are limited to fixes that keep this exact design working (broken links, encoding issues, browser compatibility) — for new features or a redesign, see the live [instancepage](https://github.com/StuxCloud/instancepage) repository instead.
